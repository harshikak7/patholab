# PathoLab – Online Pathology Booking System

A full-stack pathology booking platform that enables users to book lab tests, schedule home sample collection, track appointments, and access test reports through a secure and responsive web application.

## Features
- User authentication (JWT & Google OAuth)
- Home sample collection booking
- Test report access
- Role-based user and admin dashboards
- Admin management for users, bookings, tests, and reports

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Firebase Authentication

## Run Locally
### Backend

```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
